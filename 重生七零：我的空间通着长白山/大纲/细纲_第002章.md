# 细纲（第 2 章）

### 第 2 章：四口人的下一顿
- 核心事件：陈守山在队里求活碰了软钉子、被记工员一干人背后看轻，回家路上摸清空间的时间与取用规则，用空间取出的水和山货给家里凑出一顿稀的，同时被母亲起了疑。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01；单元第二拍「建立期待」（家里揭不开锅、妹妹念书没钱、父亲咳嗽；主角摸清空间规则）
- 目标情绪：读者从「替这家人揪心、替主角被人看轻不平」走到「看见他在夹缝里站稳脚跟」。先把断粮、闲话、队里的冷眼和父亲的病压满，再落到他不动声色地替家里凑出一口吃的、在心里定下第一步。本章推进单元情绪引擎的「缺口维持原因」一环：重生者空有眼界却没有本钱、没有名分，出头一步都难。
- 主角目标/关键选择：他要在这个春天给家里挣出下一顿、并摸清空间能拿什么、不能拿什么；关键选择是——队长话里递了台阶（托人说句话就能挪出点口粮），他偏不走这条路，选了自己扛下没人愿意干的零碎活换工分，宁可硬顶也不低头求人（性格弱点第一次露头）。
- 章首钩子：悬念对话开局 — 从队部记工房前飘来的一句闲话起手：「老陈家这小子，跟他爹一样，是个惹不起事的命。」话说给旁人听，落进主角耳朵里。
- 爽点：无显性爽点，功能是人物塑造与规则立档。给读者的往下看理由＝主角一寸寸把空间的用法摸清（能带出什么、时间快慢），读者跟着他一起盘算「这地方能换来什么」。
- 本章禁止提前释放：① 不让主角当众显露治牲口的本事（队里「他会看牲口」留到后文才传出）；② 不解释空间来历，不写空间的地界全貌；③ 不让母亲或妹妹看出空间的底细（本章他还没打算说）；④ 不泄露山货收购价、工分分值这类后文才量化的数字；⑤ 不让周振海的真实算盘露头（留到第 28 章）。

#### 内容概括（五段式）
- 起因：家里断粮，陈守山一早去队部记工房前等活计，想跟队里先挪出一点口粮渡过春荒。
- 发展：他听见记工员与旁人背后嚼舌，说陈家这小子跟他爹一个命；生产队长周振海按规矩办事，话里递了台阶——要口粮得托人去说，他偏偏不肯。他接下旁人躲着走的零碎苦活，只换来几个工分。
- 转折：回家路上他独自试空间的用法，摸清里面的时辰比外头慢、随手取的东西能带出来——他把泉水与一点山货揣回家，掺进锅里，凑出一顿能见底的稀粥。
- 高潮：本章无高潮：规则立档与人物塑造（空间能取什么、主角宁扛不求人，两件事都在这一章立住）。
- 结尾：妹妹陈守玉扒着门框说还想念书、又说家里供不起；炕上陈栓咳得直不起腰；就在这时，赵二柱一路喊着跑进来，说他家那头母猪下崽卡住了，眼看不中用了。

#### 情节安排（多线）
- 主线推进：L01 身份线只做铺垫——他在队里被看轻，「会治牲口」这层本事按着不露，为后文出手攒落差。
- 辅线推进：L03 关系线从「确认断粮」推到「他开始往家带东西」的第一步（空间取水和山货，家里吃上一顿稀的）。
- 事件线 / 任务线：外部事件链＝求活被卡。卡出的变化：主角认下「求人这条路他不走」，只能靠自己的手脚和空间撑，为第 3 章出手治病换实物答谢留出必然性。
- 感情线 / 关系线：无显性感情线。关系变化为——父子/母子的「隔」加深一层：母亲对凭空出现的吃食起疑，他只搪塞过去，把底牌藏着（藏着掖着的人设落点）。
- 逻辑线：断粮 → 求活被软钉子挡回、被闲话看轻 → 转弯靠空间凑出一顿 → 后果/新问题：一顿顶不了春荒，空间只解决「有没有」，不解决「怎么换成本钱」，他还得找一条能见光的进项。

#### 人物关系和出场顺序
- 出场顺序：陈守山（主角）／记工员与旁人（队部前，说闲话）／周振海（生产队长）／李桂芬（起疑）／陈守玉（妹妹，说想念书）／陈栓（咳）／空间（取水、取山货）／赵二柱（章尾跑进来报急）
- 人物关系变化：本章前——陈家与队里是「最不起眼、可欺的一户」；本章后——主角与周振海之间「权威型」的冷眼关系立住（队长的门还没开），与赵二柱的发小关系在章尾被急事牵起来。
- 视角/信息差：读者与主角知道空间的用法与重生底细；队里人（记工员、旁人、周振海）只当他是个闷葫芦后生；母亲、妹妹只看见「吃食不知从哪来」。主角误判：他以为只要把活干够、工分挣够就能熬过春荒，没料到家里的粮根本等不到队里下次分。

#### 结尾设定和钩子
- 结尾设定：收束落在赵二柱冲进屋门、一句话没说完的半口气上。未解决问题：家里断粮未解、陈栓的病、妹妹念书、主角没名分不能出手。下一章推动力：二柱家的猪等不起，而队里没一个能治的人。
- 章尾钩子：紧急危机 — 赵二柱报急：母猪下崽卡住，「再没法子就没崽了」（期待度：强；承接下一章：主角第一次出手，救急换实物答谢）。
