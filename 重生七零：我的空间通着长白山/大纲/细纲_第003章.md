# 细纲（第 3 章）

### 第 3 章：二柱家那头母猪
- 核心事件：陈守山赶到赵二柱家，头一回当着人出手给难产的母猪顺胎，救下第一只猪崽，也把「他会看牲口」这件事压在了二柱家的猪圈里。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01；单元第三拍「尝试」（第一次出手救牲口）
- 目标情绪：读者从「替二柱家揪心、也替陈家这一顿发愁」走到「心里一暖」。主角一伸手，把邻家的急和自家的难同时稳住一口气。本章推进单元情绪引擎的「本轮触发」一环：邻家牲口有难没人能治。
- 主角目标/关键选择：他要救回二柱家这头母猪和肚里的崽；关键选择是——明知当着人出手会露本事、招队里的眼，他还是选了出手，但只肯出手、不肯出风头（救了就救，不让人替他张扬）。
- 章首钩子：意象预示 — 从陈守山揣着母亲硬塞的半碗粗粮出门起手，灶台上缸盖又响了一声，把他推向二柱家那口猪圈。
- 爽点：无显性爽点，功能是人物塑造与第一次「本事露头」。给读者的往下看理由＝旁人都不看好的猪，主角一伸手就见了活，落差立起来。
- 本章禁止提前释放：① 不让「陈家小子会看牲口」的消息出二柱家院子（传出留到第 9 章）；② 不让主角现场收钱、议价；③ 不渲染违规用药、违规行医的具体手法（助产只写判断与分寸，不写下药细节）；④ 不让老兽医孙广田提前登场或与主角照面；⑤ 不让队长周振海在本章改变对主角的态度。

#### 内容概括（五段式）
- 起因：天没亮，赵二柱家的母猪下崽，一只崽卡住半宿，眼看母猪也快不行了，队里没一个能下手的人。
- 发展：陈守山被二柱拽到猪圈。旁人劝二柱「先保母猪、把崽舍了」，陈守山蹲下去掰开母猪眼皮、摸了摸耳根，旁人看得出这是老把式的路数，一时都说不出话。
- 转折：他迟疑了一下——出手就等于把本事亮在明面上。可母猪喘得直抖，他到底还是让人打水、扯布，自己下手把胎位顺了过来。
- 高潮：本章无高潮：第一次出手（低压胜在「稳」，不追求场面）。第一只崽落地、活了，二柱娘当场抹泪。
- 结尾：陈守山说肚里还有一只，得守着。天擦黑，二柱要跑去村里替陈家扬名，被他一句话拦下；话音刚落，母猪又是一阵抽搐。

#### 情节安排（多线）
- 主线推进：L01 身份线——「他会看牲口」的本事第一次当着人露头，但仍被主角按在院子里，名声不出门。
- 辅线推进：L03 关系线从「往家带东西」推到「邻里的情分开始欠他」；L02 资源线不动（本章不进空间）。
- 事件线 / 任务线：外部事件链＝邻家牲口有难、无人能治。卡出的变化：主角第一次被推到「出手还是不出手」的选择前，他选了出手、但限定在不张扬。
- 感情线 / 关系线：无显性感情线。关系变化为——发小赵二柱与主角从「小时候的伴」往「一条船上的人」挪了一步（二柱成了他第一个帮着跑前跑后的人，也是将来替他骂街的嘴替雏形）。
- 逻辑线：断粮逼着主角非找进项不可 → 邻家有急、无人能治 → 他冒险出手救回猪崽 → 后果/新问题：这条「治牲口换答谢」的路被推开了一条缝，可一旦声张出去，「没名分出手」和「私自冒头」两道坎就横在眼前。

#### 人物关系和出场顺序
- 出场顺序：李桂芬（灶边，数粮缸、塞粮）／陈守山（主角）／赵二柱（拽他来人）／二柱娘（抹泪）／看热闹的旁人两三句（旁人劝舍崽）／母猪与第一只猪崽（关键物件）
- 人物关系变化：本章前——二柱家与陈家是「一样穷、一样没人撑腰」的邻居；本章后——二柱一家欠下主角一份实打实的情，二柱也把主角当成了能指望的人。
- 视角/信息差：读者与主角知道他有前世兽医的本事；二柱一家只当他「不知从哪学了两手」；旁人只看见一个闷葫芦后生蹲下去救了猪。主角误判：他以为交代二柱别说出去就能真的不传，低估了乡下「嘴上没把门的」。
- 契约风险：契约安全（出手、判断、结果全在主角手上，无配角代劳）
