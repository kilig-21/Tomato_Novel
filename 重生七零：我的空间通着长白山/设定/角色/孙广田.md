# 孙广田（老兽医 · 导师）

> 配角卡 · 关键角色｜核心设定阶段建档

姓名：孙广田（人称「老孙头」「孙兽医」）
性别：男
角色功能：导师 / 本事与人情的引路人 / 传承物「兽医箱」的旧主
与主角关系：亦师亦友的老兽医

核心特质：经验老到、嘴硬心软、有旧社会行医的江湖气

标志性特征：随身一串铜烟锅；看病只认理不认人；口头禅「牲口不骗人，人骗人」

三线时间法：
- 过去：旧社会跟着老师傅走村串户，练出一手正骨、接生、治胀肚的绝活；
- 现在：大队里半退的老兽医，手艺好但年迈，一直缺个接班的；
- 未来：把本事和人情网络传给主角后退居；关键时替主角说一句重话（第一个为「山子」背书的人）。

退场方式：中段（约第 2-3 卷）因年迈病倒，或一次进山抢救牲口的意外后卸任，把用了几十年的兽医箱交到主角手里 —— 仪式性传承；此后不再承担主线功能，以一句「话」的形式偶尔回场。

与主线关系：主角职业线上「本事」的传授者与「人情世故」的启蒙者；他的认可 = 主角在兽医这行站住脚的背书。退场是主角独立门户、升级台阶上一档起跳的标志。
