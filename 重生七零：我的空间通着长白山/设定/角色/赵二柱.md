# 赵二柱（发小 · 盟友）

> 配角卡 · 关键角色｜核心设定阶段建档

姓名：赵二柱（村里叫「柱儿」）
性别：男
角色功能：盟友 / 嘴替 / 主角第一个帮手与「任务基地」式配角
与主角关系：发小、兄弟

核心特质：憨直、义气、认死理地跟人

标志性特征：力大能吃、说话直；替主角把咽不下去的话、不便发的狠骂出去

三线时间法：
- 过去：跟陈家一个屯子长大，家里也穷，是主角小时候唯一不嫌他家的伴；
- 现在：主角出诊、做买卖时第一个搭手的劳力，也是「跑腿打听」的那双脚；
- 未来：随主角一路，后期成养殖/加工线的骨干之一（主角交给他一整摊事）。

退场方式：不退场。

与主线关系：承担「嘴替 + 执行」功能 —— 主角不便说的话、不便吃的瘪交给他，主角逼格不掉；他也是「带起一片人」的第一块砖，见证明主角从顾自家到带大家。
