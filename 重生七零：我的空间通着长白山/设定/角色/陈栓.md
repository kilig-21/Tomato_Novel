# 陈栓（主角之父）

> 配角卡 · 关键角色｜核心设定阶段建档

姓名：陈栓（村里叫「老栓」）
性别：男
角色功能：亲情支点 / 主角「护家」动机的现实锚点 / 前期阻力、后期后盾
与主角关系：父子

核心特质：老实本分、要面子、认命

标志性特征：抽旱烟，一到阴天就咳，嘴边老挂着一句「别惹事」

三线时间法：
- 过去：年轻时在伐木队（或修水利）砸伤了腰腿，干不了重活，家底因此败下来 —— 陈家穷的根源，也是他认命的由来；
- 现在：守着几亩工分田，觉得儿子「瞎折腾」，怕惹事、怕被批；
- 未来：被儿子的改变一步步说服，关键时（如儿子被扣上「投机倒把」帽子）站出来护犊子，成为陈家的「主心骨」。

退场方式：全书不退场；随日子好转，身体与心气慢慢缓过来，在主角翻身后安享 —— 作为「日子好起来」的体感温度计（他不再咳嗽、能下地，就是家运翻身的信号）。

与主线关系：主角承压时家里那道「不敢惹事」的声音，构成前期软阻力；他的转变 = 主角路线被家人认可的标志。
