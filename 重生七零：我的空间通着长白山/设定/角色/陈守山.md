# 陈守山（主角）

> 主角卡 · 全书唯一主角｜核心设定阶段建档

姓名：陈守山（村里晚辈叫「山子」，长辈叫「守山」）
性别：男
角色定位：重生回乡的青年兽医，靠「治牲口」的本事和一片通着长白山的空间，把一家从吃不饱带成一方富户，并把长白山下这一片带起来。
身份标签：重生者 / 生产队社员 / 自学上手的「土兽医」（后为公社兽医站技术骨干）

外貌特征：瘦高个、浓眉、常年一顶旧棉帽、右手背有冻疮疤、看牲口时眼神格外专注（3-5 个关键词：瘦高、浓眉、旧棉帽、冻疮疤、眼神专注）

性格关键词：话少心细、面冷心热、认死理、护短、藏着掖着（不外露）—— 矛盾面：嘴上不争不抢，心里早有盘算

核心目标：让一家老小吃饱穿暖、翻身不受欺；把这身本事用在正地方，把长白山下这一片人带起来。

核心动机（情感层，非理性）：前世的穷、病、没门路刻进了骨子里，重来一次绝不再让家里受那份罪；眼下最直接的是 —— 家里揭不开锅、父亲落下病根、妹妹还小，他回来看见的第一个画面就是空粮缸。

致命弱点（会在关键情节导致犯错）：
1. 认死理、不肯低头求人（前世吃过人情的亏，不信「靠人」）—— 关键处宁可自己扛，错过助力、得罪该拉拢的人（如与队长、收购环节的关系）；
2. 对家人（尤其弟妹）太软、护短 —— 被有心人拿家人做文章（弱点②直接对应反派的下手点）；
3. 怕再失去 —— 遇事先自己憋着，不与人商量，容易一步孤行。

口头禅/标志动作：看牲口先伸手掰开眼皮、再摸耳根（老兽医的看家动作）；遇事口头禅「能治」「不碍事」。

金手指：
- 显性金手指＝随身空间通着长白山（**成长型**，作者已定，见 `设定/世界观/长白山空间.md`）；
- 隐性金手指＝前世十几年乡镇兽医的实战经验与防疫/饲养知识（这才是他真正与众不同的东西，在那个年代是降维优势）。

标志性称呼与人设细节（重复看点）：见不得牲口受罪；对瞎折腾牲口的人不留情面（对牲口的态度即人设锚点）。

成长弧（种田文不写价值观大转弯，弧线落在三轴 + 一层心胸变化）：
- 本事轴：土兽医（会看会治）→ 公社兽医站技术骨干 → 县里畜牧系统的技术权威；
- 身份轴：生产队社员 → 群众眼里的「能人」→ 大队/公社认可的技术员 → 县里挂上号的人物；
- 资源轴：工分口粮 → 副业小本 → 养殖/山货生意 → 加工作坊/养殖场 → 规模经营；
- 心胸轴（唯一的心智变化）：从「只顾自家吃饱」到「带起一片人一起过好日子」。

三层标签（至少一层反差，用行为对照写出，不靠旁白）：
- 身份（外界看到）：不起眼的回乡青年、闷葫芦社员；
- 表现（他给外界看的）：不争不抢、老实巴交、被占便宜也不吭声；
- 内核（真实打算）：重生者的清醒与盘算 —— 知道自己要往哪走、一步步布局，关键抉择时才亮出来（亮得越晚越震撼）。

红线自检：不圣母（护家守底线、行善换回报，不吃自己人的利益换名声）；非无脑战斗机器（靠手艺与判断取胜）；内核不邪恶；犯错源于性格/信息差而非蠢；不自暴自弃 —— 通过。
