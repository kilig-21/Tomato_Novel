# 长白山空间（金手指）

> 影响全书的世界观设定 · 一题一文件｜核心设定阶段建档
> **规则与上限已由作者确认（2026-10-24）**：取成长型；空间来历**不设悬念**，当天生金手指。本文件为已定稿设定，可当既成事实引用。

## 一、已定框架（作者已定，不可改）

- 书名与核心梗即定：主角随身带着一个空间，**通着长白山** —— 一片与人世隔开的山林/山谷。这是本书最大的资源来源，也是与同类题材的差别化卖点。
- 空间是主角的**核心资产（利益安全线）**：不得无交换地被上缴、征收、或分给旁人；谁要动，须给主角可见交换，或成为主角反击的由头。

## 二、已定规则（成长型）

| 规则项 | 本书设定 |
|---|---|
| 空间内容 | 初始极小：一眼泉 + 一亩荒地。随剧情扩张，长出药圃、鱼塘、果园、田 |
| 时间流速 | 内部快于外界（外头一袋烟，里头够干半晌活；便于加工、晾晒、存货） |
| 能带谁进 | 初期只有主角能进；**后期可带少量特定的人** —— 需剧情解锁（属终局底牌，见 `设定/题材定位.md`） |
| 能带什么出 | 随手取的物资、小牲口/家禽；后期可放大牲口、带活物 |
| 资源上限 | 可人工种养繁殖，越经营越多（成长型核心：投入→产出的正循环） |
| 泉水功效 | **无**（作者已定）—— 只清冽好水，不治病、不恢复体力、不净化、无任何超自然作用。主角治好的牲口是因为他会治，不是因为水 |
| 成长性 | 有：逐卷解锁，防写无可写 |

**扩张节奏**（与 5 档升级台阶同步，每档解锁一档能力）：
① 自家与小队：一泉一亩，只够自用与零星山货；② 大队与公社：可种药圃、养少量家禽；③ 兽医站与县畜牧系统：鱼塘、果园成型，产出开始能换真钱；④ 县域跨公社：可放大牲口、可带特定的人进出；⑤ 地区与改开大潮：规模经营的底气（不再靠空间独家供资源，而是靠已立住的名声与渠道）。

## 三、防崩坏设计（必须遵守）

- 空间解决「有没有」，不解决「怎么用」：拿得出山货/药材，但换成钱、换成人情、立住名声，仍要靠主角的手艺、判断和人脉 —— 保证主角的代理权与选择权不被金手指抢走。
- 空间不能替代出诊单元：每个剧情单元仍以「治牲口/解难题」为主推线，空间只补资源，避免沦为主题空洞的「无限取物」。
- 升级后先展示新能力，再引出更大的矛盾（空间产出越多，越可能招来觊觎、暴露风险）—— 「刚好解掉眼前矛盾，同时露出更大的矛盾」。
- 上限属终局底牌：禁止未到解锁档就把空间顶到天花板。

## 四、空间来历（作者已定：不设悬念）

- **不解释来历，当天生金手指**。读者不追问也不出戏。
- 主角前世就有这片空间，但只敢在泉边取水，从没动过那亩荒地——这是他前世一直受穷的原因之一；重生后他才敢把这块地用起来。
- 因此本书**没有「空间为何跟着他」这条伏笔**，写细纲和追踪时不要把来历当未解之谜埋线，也不要在正文里暗示「有朝一日会揭晓」。
- 与之相对，长线钩子改由这两条承担：① 长白山那头到底通向哪里（作为空间的自然边界，只写「能到哪、有什么」，不写「为什么」）；② 陈家能不能真正翻身、不再受人拿捏。

## 五、红线自检

- 不得出现「空间被上缴/被夺」而无交换的情节（利益安全线）。
- 不得用空间跳过「攒钱—立名—换门路」的过程；单笔收益遵守 `设定/世界观/七十年代东北乡村.md`「六」的量级（野山参数十元封顶）。

## 六、第①档的具象（第 1 章首次出现，后续沿用）

- 入口：主角独自凝神，眼前景物淡下去，换出山谷景象；再一提气即回到原处。进出无需仪式、有旁人看着就不能进。
- 那眼泉：石头围着，一丈见方，水从石缝里往外冒，清得能看见底下的石子；泉边一圈青草，比外头的柳芽早一个节气。
- 那亩荒地：草长得密、土却厚，黑土翻上来是湿的、松的，抓一把能捏成团，多少年没人翻动过。
- 远景：坡上是一片黑压压的林子，松涛一阵一阵荡过来，比靠山屯后山那片厚，望不到边。
- 手感口径：从空间出来，手里沾的泉水凉意会留在掌心（第 1 章末用过一次；后续若复用，按同一条写）。
