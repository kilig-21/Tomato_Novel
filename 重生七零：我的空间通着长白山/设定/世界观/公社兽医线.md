# 公社兽医线（职业与本事体系）

> 影响全书的世界观设定 · 一题一文件｜核心设定阶段建档
> 本书差别化支点：主角的职业线做实在 —— **一次出诊 ＝ 一个剧情单元**。

## 一、年代的兽医行当

- 层级：多数大队/公社只有一两个「土兽医」（半农半医、兼职看牲口）；县畜牧兽医站是「正规军」，管防疫、配种、配兽药。
- 工具：兽医箱（铝/木箱，装针管、镊子、剪子、药瓶、缝线、套管针）、牛鼻钳、绷带；听诊器是稀罕物。
- 兽药匮乏：以土办法、草药、经验为主，抗生素/疫苗稀缺 —— 这正是主角前世知识的「降维优势」所在。

## 二、主要牲畜与常见病（出诊素材库）

- 耕牛（命根子、最重要的生产资料）：胀肚（瘤胃臌气）、不反刍、蹄病、产后病（胎衣不下）、拉稀、外伤、难产。
- 马、骡、驴（运输畜力）：蹄病、鞍伤、结症、外伤。
- 猪（家庭副业主体）：猪瘟、丹毒、喘气病、下痢、母猪难产、寄生虫。
- 羊、家禽：疥癣、寄生虫、鸡瘟。
- 传染病与防疫：口蹄疫、猪瘟等一旦发作往往整片牲口遭殃 —— 可做主推线的「大事件」（一次防疫 ＝ 一个高潮）。

## 三、出诊 ＝ 一个单元（单元模板）

一次出诊单元包含六拍：

谁家的牲口干什么活 → 得了什么病 → 旁人怎么误判、有没有人挡道 → 主角用什么办法（前世知识 + 土法子）→ 治好/救回的价值与答谢 → 顺带得到的信息、人情或资源（下一单元的钩子）。

- 「对象」逐级升级：本小队 → 邻队/邻村 → 大队 → 公社 → 外公社/县（与升级台阶同步）。
- 「顺路」是主角的信息网：兽医走到哪，家长里短、行情门路、谁家缺什么，都听得见 —— 这是主角经商与搞资源的天然接口。

## 四、本事来源与边界

- 显性本事：前世乡镇兽医站十几年的实战经验（看诊、防疫、配种、饲养管理）。
- 隐性本事：重生的「信息差」（知道什么值钱、哪条路子以后能成）。
- 边界：本事不是「包治百病」；牲口能不能救，取决于年代条件、主家配合与主角的取舍 —— 留出胜负起伏，不给主角随时兜底的靠山。
- **合规**：写行医用药贴合年代基数与基本常识，不渲染违规用药、违规行医的具体手法，避免误导。

## 五、与主线/金手指的接口

- 兽医线是「人推事件」的发动机：主角靠本事建名声 → 名声带来人脉与信任 → 人脉与信任变成资源与门路。
- 空间（通长白山）补的是「资源与成本」：稀缺兽药、山中草药可由空间获得/替代 —— 手艺与资源互为表里。
- 「一次出诊一个单元」＝ 核心梗（弥补遗憾 · 可重复型）的运行载体：每一个被救回的牲口，都是一次「遗憾被扳回」。
