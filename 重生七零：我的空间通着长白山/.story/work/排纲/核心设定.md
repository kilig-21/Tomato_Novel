# 任务包：出核心设定提案

按下面 Phase 2 的流程，把核心设定写成文件：`设定/题材定位.md`（在定方向时已写的部分上补全，不删作者已定的内容）、`设定/关系.md`、主角与关键角色的 `设定/角色/{名}.md`、影响全书的 `设定/世界观/{主题}.md`。作者在定方向时说过的话都在 `设定/题材定位.md`，先读它；拿不准的写成二选一的候选留给作者定，不替作者拍板，物价、收入、力量档位这类全书刻度按下附「新增物三级」属先问作者，只给候选。不出卷纲、不写正文。写作技法只读本包，外加包末「按条件可读」里条件满足的那几节。交付后只回：写了哪些文件、主角与核心冲突各一句、要作者定的事（没有写「无」）。

包里流程写到的脚本命令（取段、`--check`、`check-outline-contract.js`）由主会话在你交付后跑，你不执行命令；需要的取段结果已放进包里。

### Phase 2：核心设定

开头先看 `.active-book`：上一时刻漏建就按「定方向交付前」补建。从 Phase 1 确定的目标情绪出发，在题材框架中找到对应的剧情模式，从对标书提取可复用模块（把具体角色看成功能位），用用户自己的角色和设定填充。

完整开书时定设定交付这几样（仅规划时只落与所请求结构有关的已定设定），模板见文末：
- `设定/题材定位.md`：在定方向已写的基础上补「核心设定」（一句话梗概、主角、世界观骨架、核心冲突与终极阻碍）、读者契约、终局底牌、核心梗三分法与对标分析（表保留 2-3 行摘要，详见 `对标/`），不删作者已定；
- `设定/关系.md`；
- 主角与关键角色的 `设定/角色/{名}.md`（character-basics.md 主角卡/配角卡）；其余角色出细纲时增量补；
- 影响全书的 `设定/世界观/{主题}.md`（力量体系、社会结构等一题一文件，题材定位只留骨架一句）。
- `设定/题材正文提示卡.md` 开书时不建，写第 1 章前由写前召回生成。

**数值先问作者**：物价与收入量级、境界/力量档位、金手指上限这类影响全书的刻度，按 SKILL.md「新增物三级」属先问作者——在提案里给 1-2 个候选请作者定，确认后才写进设定，不直接写死、只在汇报里概括。

## 第1节：主角卡

### 填空模板

```
姓名：
性别：
角色定位：（一句话说清主角在故事中的功能）
身份标签：（如：废柴大学生、前特种兵、落魄皇子）
外貌特征：（3-5 个关键词，要有记忆点）
  例：瘦高、总穿旧夹克、左手有疤、眼神懒散
性格关键词：（3-5 个，必须有矛盾面）
  例：嘴毒心软、看似冷漠实则护短、冲动但有底线
核心目标：（全书终点想达成什么）
核心动机：（必须达成的理由——情感驱动，非理性驱动）
致命弱点：（让角色犯错的性格缺陷，非能力缺陷）
口头禅/标志动作：（让读者秒认的标签）
```

### 设计要点

- 动机必须是情感层面的——"为母亲复仇"优于"要成为最强"
- 弱点必须会在关键情节导致主角犯错，否则不是弱点
- 外貌和口头禅是读者记忆锚点，必须写
- 起名贴合故事的时代、地域和文化，别用与设定冲突的现代化或政治化名字；写同人或既有世界观时，原著角色沿用官方本名/译名不自造，新角色顺着原著对应地域的命名和译名风格来，同一地域不混语系

## 第2节：配角卡

### 填空模板

```
姓名：
性别：
角色功能：（导师/盟友/情报源/牺牲品/镜像对照）
与主角关系：
核心特质：（1-2 个关键词）
标志性特征：（一句话让读者记住）
退场方式：（何时/如何退出故事）
```

### 设计要点

- 每个配角必须有明确功能——没有功能的角色不要出场
- 配角退场要主动规划，不能写着写着忘了
- 同一场景配角不超过 3 个有台词
- 起名跟着设定的时代、地域、文化走；同人或既有世界观里，龙套和新配角也要顺原著对应地域的命名风格，别混语系、别塞与设定不符的现代化或政治化名字

## 第3节：反派设计

### 3.1 反派层级表

按反派要撑多长的剧情选层级，按表格要求设计。

#### 小反派（一个剧情单元内解决）

| 维度 | 要求 |
|------|------|
| 功能 | 一个剧情单元的障碍 |
| 设计 | 1-2 个鲜明特征即可（嚣张/贪财/欺软怕硬） |
| 退场 | 被打败或被揭穿，干脆利落 |

#### 中等反派（一卷的主对手）

| 维度 | 要求 |
|------|------|
| 功能 | 一卷的主要对手 |
| 动机 | 为什么跟主角作对（不能是"纯粹的坏"） |
| 手段 | 武力/权谋/资源 |
| 逼格 | 至少赢主角一次，让读者恨得牙痒 |
| 退场 | 被主角正面击败，要有爽感 |

#### 大弧Boss（一卷或数卷）

| 维度 | 要求 |
|------|------|
| 功能 | 代表一个阶段的核心矛盾 |
| 人弧 | 完整的人物弧线，有自己的目标和逻辑 |
| 冲突 | 与主角有理念冲突（不只是利益冲突） |
| 对决 | 至少一场让主角陷入绝境 |
| 侧面 | 有一个让读者"恨不起来"的侧面 |
| 退场 | 有仪式感的终战 + 有余味的落幕 |

#### 最终Boss（全书）

| 维度 | 要求 |
|------|------|
| 功能 | 全书核心矛盾的具象化 |
| 伏笔 | 从第一章就有 |
| 对立 | 与主角的目标/动机直接对立，代表故事主题的反面 |
| 实力 | 碾压主角，主角必须蜕变才能赢 |
| 信念 | 有信念，不是纯粹的疯子/怪物 |

### 3.2 反派设计铁律

- 反派的智商/实力决定主角的含金量——反派弱 = 主角赢没意义
- 反派的行为必须有内在逻辑（从他的视角说得通）
- 不要让反派降智来给主角送赢

### 3.3 反派建立四要素

按顺序操作，缺一不可：

1. **实力展示**——出场就展示实力或手段
2. **动机可信**——从反派视角看行为说得通
3. **真实威胁**——至少赢主角一次
4. **终极意图时机**——真实目的留到关键反转点

### 3.4 反派性格确立四步法

| 步骤 | 操作 |
|------|------|
| 1. 反派也有梦想 | 在反派眼中他是自己故事的主人公 |
| 2. 挖掘创伤性过去 | 谁抚养他？谁爱他？谁伤害他？他避免什么痛苦？ |
| 3. 磨练性格缺陷 | 遭遇逆境时不调动积极特质，而是磨练缺陷——"优势"本身就是致命缺陷 |
| 4. 反派是主角的镜子 | 反派的长处反映主角的弱点，两者完全相反 = 每次相遇必然摩擦 |

### 3.5 反派渲染分量的关键

- 障碍从反派人设上来，而不是故意给主角制造障碍
- 反派渲染公式：明确动机 → 动机驱动行为 → 行为形成障碍 → 障碍强度来自反派分量
- 反派异常强势时，主角要破得"高级""智慧""出乎意料"

## 第4节：动机设计

### 4.1 动机链模板

```
起因（Cause）    → 角色经历了什么
意图（Intent）   → 角色想做什么
约束（Constraint）→ 什么在阻碍他
风险（Risk）     → 失败的代价是什么
```

**示例**：
```
起因：母亲被仇家杀害
意图：找到凶手并复仇
约束：凶手是当朝权臣，主角只是平民
风险：复仇失败会被灭门，复仇成功会失去所有现有生活
```

### 4.2 动机链设计要点

- 起因必须具体——"被欺负"不够，"在众目睽睽下被打耳光"才行
- 约束必须有力——否则主角一路碾压没有张力
- 风险必须真实——读者要相信主角真的可能失去重要的东西
- 动机可以随剧情演变，但不能说变就变
- 起因从三处找：世界压迫（没实力就自保不了）、金手指带来的利益、亲友的遭遇
- 外力动机之外再给一个内在梦想；目标要贴身份，宗门圣女想救宗门可信，杂役弟子想救宗门就缺说服力

### 4.3 动机冲突类型

遇到角色需要内心挣扎时，从下表选一种冲突类型：

| 类型 | 定义 | 示例 |
|------|------|------|
| 目标 vs 道德 | 想做的事和应该做的事冲突 | 复仇但不想伤及无辜 |
| 情感 vs 利益 | 感性和理性的拉扯 | 知道对方不可靠但放不下 |
| 短期 vs 长期 | 眼前利益和远大目标的矛盾 | 妥协保命 vs 坚持原则赌未来 |
| 自我 vs 他人 | 个人需求和他人期望的冲突 | 想过平静生活但背负家族使命 |

## 第5节：角色塑造方法速查

### 5.1 角色塑造核心原则

**主角行为三必须**：
1. **必须可理解**——读者必须理解主角为什么这么做
2. **必须可共鸣**——主角的思考读者必须能代入
3. **必须可接受**——主角的三观读者必须能接受

**展示优于告知**：
- 角色的目的 → 通过行为展示，不是旁白解释
- 角色的行动 → 具体的动作和决定，不是形容词堆砌
- 角色的态度 → 通过对话和反应体现，不是心理独白

### 5.2 反差设计

给每个重要角色填三层标签，至少一层和另两层相反：

| 层 | 含义 | 例 |
|---|---|---|
| 身份 | 外界看到的身份 | 豪门弃妇 |
| 表现 | 他展现给外界的行为 | 被骂不还口，被赶不反抗 |
| 内核 | 真实的打算和性格 | 悄悄录音、收证据、提前转走财产 |

- 反差用行为对照写出来，不靠旁白点明；内核留到关键抉择时亮出来，亮得越晚越震撼。
- 找反差可以让外表、身份、爱好、性格两两错位：看着凶实际心软、杀手擅长插花、豪门子弟住地下室。
- 主角和核心配角给一层强反差；功能性配角贴一两个标签就够，不强行立体。要保持神秘和压迫感的高手可以留扁平，写透来历和软处反而显弱。
- 反差太大会劝退一部分读者，按本书读者口味控制尺度。

### 5.3 展示人物特质的方法

| 方法 | 操作 | 示例 |
|------|------|------|
| 敏感性 | 触碰弱点，看反应方式 | 惊慌失措/匆忙逃跑/转移注意力=不同性格 |
| 逃避 | 展现回避行为暗示弱点 | 角色的"不做什么"比"做了什么"更揭示深层性格 |
| 先正后缺 | 先展示吸引人特质，再揭示缺陷 | 读者先喜欢角色，才能容忍缺陷 |

### 5.4 配角用法

- 嘴替：主角不便说的话、不便发的狠、不便吃的瘪，交给一个忠心配角或伙伴，主角的逼格不掉。
- 任务基地：选一个配角同时挂着几件短期和长期的事，主角每收完一个剧情单元回到他那里接新事；他下线时给主角更大的好处。
- 以角色带角色：读者喜欢某个角色，就写他的家人、闺蜜、对头，喜爱跟着延续；读者不感兴趣的角色及时下线。

### 5.5 人物经历三线时间法

| 时间线 | 内容 |
|--------|------|
| 过去 | 身世背景、遭遇变故、性格成因 |
| 现在 | 与主角的关系定位、当前互动模式 |
| 未来 | 制造变强动力或危机（老师被劫/女主被抓/反派揭底） |

### 5.6 配角执念设定法

快速让读者认同支线配角：

- 给角色一个执念 → 所有行为/爱好/性格围绕执念展开
- 不需要每次贴合执念，只要不写与执念冲突的东西，关键时揭示即可
- 过于极端的执念 → 加入"亲民"小细节 → 便于读者认同
- 适用：支线配角，不适合频繁出现的主要配角

### 5.7 人物行为重复点设计

维持长篇不歪的关键手法：

- 抓住一个人物行为特质反复写
- 构建方法：确定读者喜欢什么类型 → 具体化为行为 → 不同场景重复
- 人物看点 + 核心看点 = 层次感，两者循环产生差异化
- 反派/配角也需要重复看点，能让人爱上的反派会增加读者新鲜感

### 5.8 围绕人设写行为

行为、语言、思维都要围绕人格展开。如果为了剧情需要让角色做出不符合人设的行为 → 先修改剧情，不要改人设。

### 5.9 人推事件 vs 事件推人

| 驱动方式 | 特点 |
|---------|------|
| 人推事件 | 情节是人物性格/动机/选择的自然结果，深化人物弧光 |
| 事件推人 | 外部事件打破平衡，迫使暴露真实自我 |

卡文时 → 从人物动机找方向，不要硬编剧情。

## 第6节：主角特殊问题

### 6.1 主角逼格

- 主角必须有逼格——这是读者的代入基础
- 不要写太多降智的内心戏和爆粗口
- 主角可以不完美，但不能让人看不起
- 被挑衅时的反应随实力和阅历变：实力高就轻描淡写，实力不够就隐忍蓄力；气急败坏地反击是毒点

### 6.2 主角的成长弧

成长按四段写，每段要有读者看得见的事件：

1. 触发：一件事打破现状，主角原来的办法或信念不管用了
2. 变化铺垫：主角试新办法、付代价，可以反复，每次留一处行为上的变化证据
3. 转折点：关键抉择时，主角第一次按新的方式选
4. 新状态：之后同类局面里，主角稳定用新的方式行动

- 成长写在心智和选择上，不只写在实力上。
- 网文主角不一定要成长：开场三观圆满、人设稳定的主角更容易代入，弧线可以只放在实力和地位上。

### 6.3 主角红线

以下类型的主角绝对不要写：

| 禁止 | 说明 |
|------|------|
| 圣母型主角 | 以德报怨、拿自己人的利益换好名声，读者要的是痛快；守底线、行善后有回报不算圣母 |
| 无脑战斗机器 | 难以产生情感共鸣 |
| 内核邪恶 | 读者无法代入 |
| 因蠢、圣母心或与实力不符的低级失误犯错 | 读者无法原谅；因不可抗力或信息差犯错可以 |
| 自暴自弃 | 比被欺负更让读者厌恶 |

### 6.4 主角调子起太高怎么办

**危害信号**：
- 失去成长空间——能力/地位/资源触达天花板
- 剧情缺乏张力——陷入"砍瓜切菜"的重复循环
- 读者失去追更动力

**化解方法**：
- **降调不降人**——压低气势和期待，但不打压主角本身的能力和尊严
- **留出维度差距**——即使某方面很强，总有其他维度是短板
- **超额收获法**——看似收获很大，经主角盘算后发现更大
- 紧张题材（极道、末世、悬疑）别给主角随时能兜底的靠山，靠山不能消掉危机感

### 6.5 主角开篇立人设

- 人设靠选择立：开篇让主角做一次选择，读者从选择里看出他是什么人。
- 无敌流、认知差这类开局，靠主角怎么用力量的选择立人设，不靠战力展示本身。
- 行动力从三处显：做别人不敢做的事、做别人做不到的事、做别人没想到能这样做的事；行动要有人设上的缘由，不为制造意外崩人设。
- 主角有不讨喜的一面（好色、贪财、记仇）要在开头亮明，后面别突然转性。

### 6.6 主角的两个身份与两个金手指

| 维度 | 定义 | 作用 |
|------|------|------|
| 显性身份 | 社会身份/职业+状态 | 汇集前期矛盾，必须不断升级或换 |
| 隐性身份 | 不凡的身世来历 | 汇集中后期矛盾 |
| 显性金手指 | 系统/玉坠/重生记忆 | 开局获得贯穿全书 |
| 隐性金手指 | 主角性格 | 让主角与众不同的就是金手指 |

**最佳写法**：前 3 章用一次选择立住人设（见 6.5），之后靠金手指场面把人设一层层加深
**人设与全书气质**：主角人设必须与世界基调相符，四点高度统一：社会身份+身世+金手指+性格

## 第7节：反派塑造深化

### 7.1 反派塑造核心原则

- 经典反派一定有完整世界观和逻辑自洽的三观
- 同样的外部事件发生在不同人身上产生不同变化——外因与内因共振
- 反派塑造不能只有外部事件，缺乏内在三观和内在逻辑

### 7.2 反派人设主角化写法

**传统问题**：换地图后原反派跟不上节奏 → 引入新反派脸谱化

**解法**：
- 把反派当主角去写
- 在"配角衬主角"基础上加"配角衬配角"
- 换地图的正确处理：用新地图衬托旧角色含金量，而非用旧角色无力衬托新地图难度

## 质量检查清单

设计完角色后，逐项检查：

### 主角检查

- [ ] 动机是情感层面的（不是"要成为最强"这种空话）
- [ ] 有致命弱点，且会在关键情节导致犯错
- [ ] 外貌有记忆点（3-5 个关键词）
- [ ] 有口头禅或标志动作
- [ ] 逼格在线——不会让读者看不起
- [ ] 没有触碰红线（圣母/无脑战斗机器/内核邪恶/因蠢犯错/自暴自弃）
- [ ] 核心目标和全书主线对齐
- [ ] 主要角色有三层标签，至少一层反差，用行为对照写出
- [ ] 影响剧情走向的设定（实力、钱、人脉、背景）至少 3 项，爱好只做记忆点

### 配角检查

- [ ] 有明确功能（导师/盟友/情报源/牺牲品/镜像对照）
- [ ] 核心特质 1-2 个关键词能概括
- [ ] 有标志性特征让读者记住
- [ ] 退场方式已规划
- [ ] 同一场景不超过 3 个配角有台词

### 反派检查

- [ ] 按层级表设计，篇幅与层级匹配
- [ ] 出场展示了实力或手段
- [ ] 动机从反派视角说得通
- [ ] 至少赢主角一次（中等反派及以上）
- [ ] 没有降智送赢
- [ ] 大弧Boss有理念冲突（不只是利益冲突）
- [ ] 最终Boss从第一章就有伏笔

### 动机检查

- [ ] 起因具体（不是"被欺负"这种模糊说法）
- [ ] 约束有力（主角不能一路碾压）
- [ ] 风险真实（读者相信主角可能失去重要东西）
- [ ] 动机演变有铺垫，没有说变就变

### 塑造检查

- [ ] 角色目的通过行为展示，不是旁白解释
- [ ] 行为/语言/思维围绕人设展开，没有为剧情改人设
- [ ] 主要角色有行为重复点，维持长篇一致性
- [ ] 配角与主角有明确联系，不会抢主角风头
- [ ] 内核标签在关键抉择时亮出，没有提前用旁白交代

## 核心梗三层递进设计（表层卖点→深层爽点→长线钩子）

一本书通常有 2-4 条核心梗。三层按设定模板的三个字段填写：

### 三层怎么填

| 模板字段 | 是什么 | 怎么找 | 失败信号 |
|---------|-------|-------|---------|
| 表层卖点 | 这个题材独有的吸引力，用来筛读者、划边界、出氛围 | 看同题材火书靠什么卖、读者冲着什么进来 | 卖点偏到别的题材；书名暗示的和正文给的不一致 |
| 深层爽点 | 读者反复追的一条情绪链（期待→满足），如扮猪吃虎、弥补遗憾、莫欺少年穷；装逼打脸只是表现形式 | 从人人都有的情感里抽一种：推到极端（日常委屈推到生死或巨额对赌），并只咬住这一种贯穿全书，其他情绪都为它服务 | 情绪散乱、几条小情绪各走各的 |
| 长线钩子 | 支撑全书的目标或悬念，主线要落成一件事 | 用一句话写出主线事件：《斗破》是「被退婚→上云岚宗复仇」，《全职》是「被辞退后重回巅峰」；升级只是达成目标的手段；立意落在主角要证明什么 | 只有升级没有主线；没有立意，文字干巴巴 |

深层爽点还要写清运转方式：

- **可重复型**：每个剧情单元运行一次，变换场景、对象和条件（升级文、系统文、文抄娱乐）。
- **一次爆发型**：贯穿全书，只在最高潮爆发一次（追妻、掉马、禁忌之恋）。
- **长期铺垫型**：以期待点的形式贯穿全书（悬疑、复仇、解谜）。

第一个剧情单元就要运行一次核心梗，或完成它的首次铺垫。可以布两条线：一条重复运行核心梗，另一条不重复，两条交替推进。

### 剧情构建顺序

核心卖点 → 情绪套路 → 具体剧情：先定读者要看的情绪，再定怎么让读者感受到，最后选用什么事件。

### 核心梗定义

核心梗是金手指最核心的用法加读者最想看的爽点模式。金手指是工具，核心梗是它最好看的用法。核心梗可以换背景平替（女帝换成朱元璋、嬴政）。

### 每章循环检查

每章至少满足一项：有核心梗相关的期待点；有核心梗相关的爽点；处在两者之间。

**断期待**：某章既没有期待点也没有爽点，上一个爽点已经结束，本章又没拉起新期待，读者会觉得书没了魂，开始弃书。

### 常见误区

- 核心梗太多：什么都想写，等于没有核心梗。
- 只有装逼打脸、没有主题：剧情没有意义，主角的目标要让读者觉得值得。
- 核心梗用完不升级：重复显得生硬，按「爽点阈值递升」加码。
- 挂羊头卖狗肉：书名、简介、前三章给的卖点和后文不符。
- 偏离题材核心：对比对象或对手跳出本题材（都市高武写着写着和异界神比），读者冲着来的东西没了。
- 刀人是手段：悲情靠挫折体现，不靠身边人死绝；换地图不清空旧角色攒下的关系和资产；身边人遇险后要能最终克服，不全当工具人；长段悲壮要穿插别的情绪。

### 防崩盘三检查

1. 能用一句话说清题材核心卖点的目标情绪。
2. 卖点能拆出至少 5 个不重复的剧情展开方向。
3. 展开卖点需要的写作能力，现有方法能覆盖。

## 金手指

### 选型

金手指替掉故事流程里的哪一环，决定它怎么推剧情：

| 替掉的环节 | 写法 |
|-----------|------|
| 建立目标 | 系统发任务 |
| 克服困难 | 一键解决，但要付代价 |
| 准备过程 | 跳过苦熬，直接撞上阻碍 |
| 收获奖励 | 做 A 得 B，如做好事获利 |

选型时对三样：

- **贴职业和处境**：医生配医术合理，配隐身牵强。同一项能力升级、衍生出不同效果，不频繁另开新金手指。
- **贴人设**：开朗搞笑型配自爆类，心狠手辣型配升级掠夺类；冷酷人设配搞笑金手指会违和。金手指规则还能替性格找理由：规则逼主角这样做，配角的反应自然把人设立起来。
- **贴世界压迫度**：阶级固化、环境恶劣的世界配无条件加点；换地图升级的常规世界配碎片或解锁型；轻松日常配人际或种田型。功能单一的金手指只适合强压迫世界，其他题材要另补解法。

金手指要同时能开挂、能不断拉出新目标推进主线；脱离核心卖点或题材边界就回正。

### 规则

- 简单，一眼能懂，游戏化面板最好。信息类最不易失控，加速升级类其次，物品调用类最容易失控。
- 条件→反馈分三档：单条件单反馈（摸尸得宝）；攒点解锁的阶段反馈（摸尸得点数，攒够解锁新功能）；可融合的升级反馈（击杀掠夺词条，词条能融合，后期天花板更高）。逆向型单列：失去 X 换来更强的 Y（越惨越强、负债越多越有钱）。
- 有限制，主角才会一步步行动。给出后当场要有看得见的变化。
- 主角是规则里的特殊变量；设定服务剧情，不反过来被设定捆住。
- 升级要付风险或触碰既得利益（同一序列的超凡者都是对手），矛盾线自然就有了。

### 上限与代价

- 上限是终局底牌之一：在设定的「终局底牌」里标最早解锁的卷，具体数值先问作者。
- 三问：主角资源翻上百倍后，它还能解决主矛盾吗？会不会抢走主角的判断和选择？它和世界之间有没有可写的反差？
- 金手指太强、矛盾不够，读者无聊；金手指太弱、矛盾太强，读者焦虑。最好是刚好解掉眼前矛盾，同时露出更大的矛盾。升级后先展示新能力的威力，再引出更大的危机。

### 成长路线

- 至少两个维度同时长（词条、功能、品质）。后期只剩品质提升，提升感就没了。
- 四阶段：基础（明确核心作用，让读者认得它）→ 发展（加新用法，核心作用不变）→ 成熟（和世界观深度结合，能与其他体系联动）→ 升华（作用对象从个人扩到世界层级，要有足够伏笔）。重心可以转，不能完全抛弃，呈现力度随阶段加大。
- 碎片化：把复杂能力拆成碎片融进剧情，没集齐是远期期待，每拿到一片至少解决一个冲突。
- 金手指的核心用法每个剧情单元都运行；相邻单元的用法至少换一项：对象、条件、代价或解法。
- 天才流多设等级档位，防止数值几十章就到顶；无敌流把循环核心换成信息差，来一个秒一个，每次都刷新旁人的认知。

### 防战力崩坏

- 三个常见原因：没写升级线（用成熟的境界体系做框架）；只靠单一维度提升；社会关系太简单（补师门、酒馆、朋友、情报组织）。
- 量级按题材边界定，单体能力够用就不上多元宇宙；规则类能力最容易失控，尽量回避。
- 等级高的人占高位；主角跨大境界对敌，要给出原因（代价、底牌或环境）。

## 人物关系类型

查表确定角色间的关系类型，然后按原则执行。

| 关系类型 | 定义 | 功能 | 示例 |
|---------|------|------|------|
| 冲突型 | 双方利益/理念对立 | 制造张力，推动情节 | 宿敌、竞争对手 |
| 联盟型 | 双方有共同目标 | 提供助力，制造羁绊 | 战友、师徒 |
| 亲密型 | 情感纽带连接 | 制造软肋，提供情感支点 | 恋人、家人、兄弟 |
| 权威型 | 上下级/支配关系 | 制造压力，限制主角行动 | 师父、老板、监管者 |

**执行规则**：
- 每个重要关系至少安排一次考验（背叛/牺牲/误解）
- 关系必须有变化弧线（敌人变盟友、盟友变对手）
- 禁止所有关系都是"你好我好"的铁板一块
- 关系的功能必须服务于情节，不能只为甜/虐而存在

# 读者契约与终局储备

本文件是 `story-long-write` 关于读者契约、主角代理权（叙事能动性/主导性）、利益安全与阶段推进的权威参考文件。判断须结合本书题材、平台和对标样本。

**安全边界**：本文件不得包含来源站点隐私数据、访问凭证、cookies、tokens、请求签名、私有标识符，或任何能反推出私域账号/请求环境的信息。

## 0. 契约四问（排纲、写正文、批末核对只用这四问）

1. 主角是不是靠自己的选择挣到了结果？（因果权 + 结算权，拿不准过「关键节点四问」）
2. 核心收益或高光有没有被配角、机构或巧合无交换地拿走？（期待所有权、利益安全）
3. 有没有动用本阶段还不该解锁的终局底牌，或把某条升级线顶到天花板？（终局储备、透支两问）
4. 旧期待付了利息没，又给读者留了什么期待？新地图、新机构、新谜团有没有被拿来逃避旧承诺？（期待债、换书债）

四问都过＝契约安全；有一问勉强但能靠铺垫/交换/成本补上＝需补强；补不上＝契约破坏。答不上来的那问再读下面对应小节。

## 1. 核心概念

### 读者契约
- 读者契约 = 开篇、题材、主角配置、叙事口吻共同许诺的阅读快感。
- 写作前先确认：读者是来看主角解决问题、见证团队群像、看导师托举后辈，还是看制度合作建设？不同契约下同一情节风险不同。

### 主角代理权：因果权 + 结算权
- 主角代理权首先看**因果权 + 结算权**，不看出场时长，也不要求主角永远亲自动手或垄断每个镜头。
- 主角不可替代首先体现为因果权：主角通过决策、布局、授权、不可替代的信息/资源，或主动选择关键后果，决定事情为什么发生、如何进入与怎样转向。
- 结算权 = 核心收益、认可、权力或关键后果依照既有承诺回到应得者。可以借力、组队、被救、接受指导或让他人执行局部动作，只要因果与结算没有被无声夺走。
- 职业/权力幻想题材尤其敏感：读者通常期待主角掌握资源、做出决策、承担或选择后果并拿回可见收益。
- 题材例外（直给爽文）：番茄战神/赘婿/打脸/都市异能等，主角亲自出手、当面碾压本身就是契约兑现，代理权不能拿来给主角划水、让下属封神；只有布局/权谋/经营/群像/导师题材才默认可幕后运筹、隔人兑现。

### 期待所有权
- 承诺的兑现/高光属于本卷或本单元已经许诺的主角或其他承诺所有者；配角可以执行局部动作，但不能无声夺走期待所有权。
- 群像、导师或制度合作可把期待所有权明确给团队成员/学生/机构角色；关键是预先承诺、按约结算，而非事后解释抢戏合理。

### 关键节点四问
第一问拿不准时逐条问（可指向本卷已承诺的其他所有者）：
1. 谁决定事情为什么发生/如何进入？
2. 谁作出不可替代的关键选择？
3. 谁承担或选择关键后果？
4. 核心收益/认可/权力最终结算给谁？

### 利益安全与兑现归属
- 利益安全 = 读者相信自己追的核心卖点不会被没收、稀释、转赠或交给无关角色消化。
- 兑现归属 = 谁铺垫、谁承压、谁选择，谁就应拿到主要情绪回报；旁观者/配角反应可以放大爽点，不能替代主角爽点。
- 核心资产（金手指、关键资源、身份底牌、独家技术、关键证据）不得无交换地交出、暴露给外部机构或被上级接管。若必须交出，需要可见交换：权力、保护、资源、渠道、名分、债权、信息、阶段胜利或更大局面的主动权。

### 期待债
- 每次埋承诺（主角会反击、资源会升级、身份会揭开、感情会推进）都产生期待债。
- 期待债可以延期，但要付利息：阶段性进展、新信息、局势变化、情绪释放或更清晰的下一目标。
- 用解释、设定或机构流程拖延兑现，会增加合理化债务。

### 终局储备与推进节奏

“写无可写”的病根是两类**宏观资源**被提前打光，跟单章涨多少关系不大。管住这两类、放开单章密度，才既不透支又不憋屈。

**两类会打光的宏观资源（开书时定，逐卷解锁）**
- **终局底牌**：头号宿敌、终极真相/身世、金手指上限、身份/地位终点、核心情感的最终确定。一次性资源，用了就没。开书时列进 `设定/题材定位.md` 的「终局底牌与升级台阶」小节，每项标最早可解锁的卷/阶段（从终局倒推成卷级里程碑，一卷只解锁一个大里程碑）。
- **升级台阶**：境界/等级/地图/势力层级的剩余档数。开书时做一次台阶检查——体系档数 × 每档停留篇幅 ≥ 全书目标字数；台阶不够是设计病，设计期补（拉长体系/加地图层），不靠每章憋。敌人/目标/地图成**梯队**，逐级解锁，禁止越级提前秒顶级 boss / 解决终极目标。

**单章 / 单个剧情单元放开密度（爽感来源，不要压）**
- 每个剧情单元设 1 条**主推线**（战力线/资源线/身份线/关系线/信息线/地图线/制度线/势力线/事业线/情感确定性等升级线其一，承担本轮最大高潮），其余线按剧情自然给**战果**（轻触到大涨皆可）。**一战多得——一场大胜同时破境、缴获、收势力、涨声望、抱得美人——是允许且常见的好设计，该给就给。**
- 章级推进按平台/题材分档：快节奏（番茄/爽文）保留“每章要有可见事件或爽点推进”的下限；慢热/种田/情感文才放宽到“改变目标 / 风险 / 信息 / 关系 / 资源 / 身份 / 情绪立场七类状态之一即可”。低压/过渡章用小而可见的变化承接，不强求每章高潮。
- 高潮/兑现后可安排一段短暂低压，让读者先拿小而可见的收益/奖励，再进下一轮压力；不强制兑现后立即加危机。
- 可选工具：行动成本/成功代价。重要成功可带时间、关系、暴露、资源消耗或新敌意等成本；低压/过渡/纯奖励章不强制附加代价。

**推进过快判定（透支两问）**
1. 是否动用了本阶段还不该解锁的终局底牌（宿敌了结、终极真相、身份终点、金手指触顶）？
2. 是否让某条升级线逼近天花板、后面没台阶接？

任一为“是” = 真正的透支预警 → 回退或改纲；两者皆否，多线齐涨放行。档位与里程碑按本书题材、平台与对标调整，不是硬门槛。

### 合理化债务
- 解释成本用于说明机构响应/接管、保密、资源调动、跨区执法、组织协作等为什么成立。
- 检查：这些解释是否服务核心情绪？若解释本身吞掉爽点、代入或主角高光，就先缩短解释、改为可见交换，或把机构反应降级为旁观/阻碍/资源接口。

## 2. 制度/机构与旁观者设计

- 提到政府、宗门总部、跨国组织、多国公司等不天然有毒；它们只是高层级叙事开关。
- 国家合作 / 政府合作类故事可以算契约安全，前提是开篇已承诺制度合作，主角保持不可替代，并获得可见权力、保护、资源、收益或更高行动权限。
- 若本书承诺的是个人逆袭、职业掌控、独享金手指，外部机构接管核心问题通常需要强交换与主角主动选择。
- 旁观者/反应层适合做：震惊、误判、舆论扩散、资源报价、敌我站队、见证主角选择。避免让旁观者替主角复仇、替主角做最终裁决、替主角拿核心收益。

## 3. 契约风险三级

| 等级 | 定义 | 处理 |
|---|---|---|
| 契约安全 | 与开篇题材契约一致；主角仍拥有关键选择/不可替代贡献；收益归属清楚 | 可写，注意把交换和收益可视化 |
| 需补强 | 可能稀释主角高光或推进过快，但能通过铺垫、交换、成本、题材声明修复 | 写前补理由、补代价或调整为阶段性而非终局兑现 |
| 契约破坏 | 没收核心卖点；自愿让渡同时造成**长期净收益为负 + 主角控制/因果权下降**（尤其没有可见战略交换）；无关角色夺走期待所有权；核心资产无交换上交或被接管 | 修纲；战略性让步可用局部聚光灯/资源换取更大控制、未来收益、关系/制度权力、信息优势，或兑现已承诺的群像/导师高光，不按让渡本身判红灯 |

## 4. 好/坏例与例外

### 职业/权力幻想主角自愿让出聚光灯
- 红灯组合：让渡同时导致长期净收益为负、主角控制/因果权下降，且看不到战略交换；不是任何自愿让渡都算 契约破坏。
- 好：主角授权下属执行，但方案、关键资源、最终谈判和风险承担由主角掌控；或用局部聚光灯/资源换取更大控制、未来收益、关系/制度权力、信息优势。下属表现反过来证明主角识人/组织能力。
- 例外：若本书从开篇承诺“导师/经营组织/群像成长”，主角的高光可以是培养体系、选人眼光和关键兜底。

### 给出资源或核心资产
- 坏：主角把独家技术、金手指产物、关键证据无条件交给机构，换来口头感谢，后续由机构推进主线。
- 好：主角交换到牌照、保护、渠道、话语权、独占收益或更大舞台，并保留不可替代的控制点。

### 无关角色替主角复仇
- 坏：压迫主角多章的敌人，被路过强者或随机事故解决，主角没选择、没出手、没获得认知/资源/地位变化。
- 好：配角可以助攻或见证，但关键证据、布局、决断、公开裁决或最后反击由主角完成。
- 例外：悲剧、悬疑、群像战争可让他人完成局部动作，但要让主角获得新的核心任务、代价或认知推进。

### 提前打光终局储备（多线齐涨本身没问题）
- 坏：一个剧情单元把全书级底牌一次性烧光——解决头号宿敌、揭终极身世、坐实终局身份、金手指直接触顶，后面没大目标可写。
- 好：本单元让主角一战多得（破境+缴获+声望齐涨），但都在体系台阶之内、不碰终局底牌；宿敌只退一个梯队、真相只揭一层，大底牌留到后续卷偿还期待债。

### 合法群像 / 导师故事例外
- 群像契约：每个 POV 有自己的目标和偿还，主角不是唯一爽点来源；卷契约应写清谁在本卷拥有高光。
- 导师契约：导师主角的高光在设计训练、识破困局、关键兜底、承担更高层代价，而不是每次亲手收割。
- 制度合作契约：开篇即承诺国家/机构协作，主角以专家、指挥者、关键资源拥有者或不可替代执行者身份获得明确权力和收益。

## 5. 续接与换书债

- **换书债**：引入新地图、新机构、新能力、新敌人或新谜团，既要支付必要的铺垫成本，也会新增期待债；不能靠新鲜元素逃避旧承诺。
- **题材特定高风险**：在履约爽文/能力幻想中，主角反复因愚蠢或可避免的无能制造灾难，再由别人收拾，会持续损害因果权、控制感和结算信任；这是依题材契约判断的高风险，不是所有故事的绝对禁令。
